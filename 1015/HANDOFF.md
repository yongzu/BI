- **01 히어로**: 혜택 한 줄(직무 인터뷰만 봐도 100만원)을 제목 위에 먼저 → 채용명(AI·ML·Data는 파란 그라데이션) → 기간 + "9일 9시간 44분 남았어요" 실시간 카운트다운 → 지원하기. 흐린 파란 곡선 배경, 아래 꺾쇠 버튼으로 스크롤 유도.
- **02 조직 소개 문장**: "왜 지금 채용하나"를 4줄 가운데 문장 하나로. 줄마다 파란 톤을 달리해 강약. 장식 없음.
- **03 혜택 3가지**: 섹션 제목 + 3행(왼쪽 굵은 2줄 제목 / 오른쪽 설명, 가는 구분선). 행이 sticky로 잠시 머물며 차례로 지나감. 각주(*제세공과금 본인 부담)는 해당 행 안 작은 글씨.
- **05 지원 분야**: 왼쪽 세로 탭(직군 + 괄호 개수, 활성 = 진한 글씨 + 왼쪽 세로 막대) / 오른쪽 2열 회색 면 카드(포지션명 굵게 + 역할 2줄), 카드 전체가 공고 링크. 포지션이 많은 직군은 패널 안에서 하위 팀(Ads, Commerce…) 소제목으로 다시 묶임.
- **06 일하는 방식**: 왼쪽 큰 제목 "Data First, 그리고 AI Native" + 설명 sticky, 오른쪽 세로 구분선과 함께 3항목이 지나감. 항목마다 작은 일러스트(성장 곡선, Experiment 카드)로 개념을 그림으로.
- **07 조직 아티클**: 3열 카드 — 인물 사진 + 분야 태그(파란 알약) + 제목 + 직함 · 이름. "누구와 일하나"를 사람 얼굴로 먼저.
- **08 기술 블로그**: 1열 리스트 — 분야 태그 + 제목, 오른쪽 작은 썸네일, 행 구분선. 07(사람 이야기 카드)과 형식을 달리해 기술 글을 구분.
- **09 지원 안내**: 2열 key-value 표(접수 기간 · 지원 방식 · 전형 과정 · 결과 안내 · 유의 사항). 전형은 → 로 단계 나열, 보조 설명은 작은 회색, 유의 사항은 불릿.
- **10 FAQ**: 아코디언 없이 "Q. 질문"(굵게) + 답(회색) 모두 노출, 끝에 회색 박스로 추가 문의 안내.
- **11 마무리**: 히어로와 같은 배경 · 타이포를 반복(기간 · 채용명 · "고민될 땐 일단 지원" · 지원하기)해 처음과 끝을 맞춤.
